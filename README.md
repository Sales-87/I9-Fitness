## I9 Fitness

Landing page da academia I9 Fitness, com informações sobre a estrutura, planos e canais de contato.

## Sobre o projeto

A página apresenta a academia e seus planos, ajudando visitantes a conhecer o espaço e entrar em contato para saber mais ou demonstrar interesse em matrícula.

## Recursos

- Seções sobre a academia, planos e contato
- Links de contato pelo WhatsApp e Instagram
- Menu adaptado para navegação em telas menores
- Animações durante a navegação pela página

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como visualizar

Abra `index.html` no navegador.
